## 创作与互动

<a id="storyloom"></a>
### StoryLoom 织界 · 故事创作与可视化

面向小说作者和互动叙事创作者，整理世界与角色、尝试故事分支，并借助地图和时间轴理解已有小说。

**阶段：开发中，源码未公开。** [查看功能介绍](storyloom.md)。

<a id="kirakira"></a>
### kirakira · AI 角色互动平台

面向角色创作者和喜欢故事对话的用户，将发现角色、塑造设定、持续互动与回忆整理放在一个空间中。

**阶段：开发中，源码未公开。** [查看功能介绍](kirakira.md)。

<a id="companion"></a>
### Human-Machine-Love · 个人 AI 陪伴

探索个人角色、日常交流与回忆管理相结合的使用体验。重点是让用户能够持续交流，并自行管理希望保留的内容。

- 创建不同性格与背景的角色，按需要切换。
- 延续日常对话，整理有意义的交流片段。
- 查看、修改、固定和保存回忆记录。

**阶段：开发中，源码未公开。**

<a id="aurum"></a>
### 鎏声 AURUM · 音乐创作工作台

面向希望把音乐想法整理成创作流程的用户，将灵感、曲风、歌词方向和视觉构想放在一起，准备后续创作材料。

**阶段：创作流程原型，生成能力仍在完善，源码未公开。** [查看功能介绍](aurum.md)。

<a id="short-drama"></a>
### AI 短剧创作工作台

面向短剧和角色 IP 的前期创作，将分散的剧本、角色和分镜放进同一工作区，方便梳理故事与沟通镜头安排。

- 整理剧本和角色设定。
- 根据剧本准备分镜，查看不同镜头的内容。
- 调整镜头顺序，形成后续制作的规划。

**阶段：创作流程原型，源码未公开。**

<a id="you-and-ai"></a>
### YOU & AI · AI 使用认知问卷

面向使用 AI、但希望更清楚理解其能力和适用场景的人。通过分阶段问答整理使用习惯与认知，再给出继续探索的方向。

- 按身份与目标完成问卷，保留作答进度。
- 通过雷达图和反馈卡梳理不同维度的回答。
- 获得规则模板生成的行动建议。

**阶段：可玩的规则问卷原型，源码未公开。**

## 业务与效率

<a id="finance-workbench"></a>
### 跨境电商财税助手

面向跨境电商经营者和财务资料整理人员，将平台结算与费用信息集中起来，准备便于人工核对的工作材料。

- 导入平台结算报表，整理销售、退款和相关费用。
- 查看期间汇总，检查资料缺口并记录人工确认状态。
- 准备申报草稿，打印或导出表格交给后续核对流程。

**阶段：业务应用原型，源码未公开。** 当前介绍范围是资料整理与申报准备，不代表税务机关直报服务。

<a id="sourcing"></a>
### 商品检索与采购辅助工作台

面向家具、材料的选品与采购前调研，用图片或描述寻找候选商品，将零散的信息整理成便于比较的材料。

- 从图片或文字开始寻找家具和材料。
- 比较商品规格，估算采购成本。
- 保留查阅和核对记录，方便后续复查与讨论。

**阶段：独立研究原型，源码未公开。**

<a id="shopping-dictionary"></a>
### 平替词典

为网购用户提供另一种搜索商品的方式：用不同用途或叫法寻找候选商品，减少只知道一种营销名称时的搜索限制。

- 查找替代关键词，复制或跳转继续搜索。
- 收藏常用条目，分享搜索思路和投稿补充。
- 通过管理工具整理词条和维护内容。

**阶段：产品原型，源码未公开。** 关键词仅用于搜索参考，不保证具体售价与商品质量。

## 生活应用与交互原型

<a id="kitchen"></a>
### 厨房助手

将菜谱浏览、冰箱食材和今日菜单选择放在一个轻量界面里，探索日常做饭前如何更方便地整理信息。

- 搜索菜品、关注菜系并查看烹饪步骤。
- 添加和移除食材，按分类查看当前记录。
- 浏览菜单选项与制作记录，减少反复寻找菜谱的操作。

**阶段：使用演示数据的交互原型，源码未公开。**

<a id="fashion"></a>
### 服饰选购与搭配

面向大尺码男装的选购体验，将商品浏览、尺码选择和搭配咨询组织在同一界面，探索更直观的零售沟通方式。

- 浏览服饰，查看商品详情和可选尺码。
- 将选择的商品加入购物车，调整选购内容。
- 通过搭配咨询入口表达穿搭需求。

**阶段：零售体验原型，结账仍为演示流程，源码未公开。**

<a id="project-consultant"></a>
### AI 服务展示与需求咨询

用于展示软件与内容创作服务，并让潜在使用者先用自然语言描述自己的项目想法。

- 浏览服务方向与作品展示入口。
- 通过咨询对话表达项目目标和需求。
- 获取初步需求拆解，帮助后续沟通。

**阶段：网站原型，源码未公开。**

<a id="tarot"></a>
### TAROT 互动体验

围绕抽牌、牌阵、内容阅读和对话设计的移动交互原型，用于文化娱乐和个人反思。不同客户端与服务端合为一项介绍。

- 选择场景，完成洗牌、抽牌与翻牌。
- 浏览牌阵与解读内容，继续围绕问题交流。
- 在相应客户端回看历史会话。

**阶段：产品原型与功能验证。** 可查看[公开的早期客户端原型](https://github.com/HoshiyomiAI/tarot-client-flutter)；其余内容仅作用途介绍。

## 复用工具与开放实践

<a id="product-foundation"></a>
### 产品基础工程

为新应用准备可以重复使用的账户和运营功能，让产品探索有统一的起点。

- 账户注册、登录、资料与通知等常见体验。
- 会员套餐和账单相关的产品入口。
- 用户检索、账户状态与日常运营管理页面。

**阶段：内部复用的基础工程。** [公开的早期应用模板](https://github.com/HoshiyomiAI/APP_BASE)与后续内部工作台合并介绍，不计作多个独立产品。

<a id="service-adaptation"></a>
### AI 服务管理适配

基于 [New API](https://github.com/QuantumNous/new-api) 的二次开发实践，用于集中查看模型服务、管理调用入口与使用情况，并探索适合日常工作的接入体验。

**阶段：开源项目适配实践，当前仓库未公开。** 保留上游归属，不将上游功能作为个人原创成果。

<a id="annotation"></a>
### Quick Annotation

面向需要处理图片标注的使用者，把候选框准备和人工复核放在本地浏览器中。可创建空白任务、补框改类、保存进度，也可按任务分段协作。

**阶段：工具源码已公开。** [查看仓库](https://github.com/utenkkekou/Quick-Annotation)。它与 PTL-Detect 属于同一视觉数据工作方向，这里单独说明轻量标注用途。

<a id="calendar-culture"></a>
### 历法与文化探索工具

围绕传统历法换算、时间校正与排盘计算构建的早期工具，为文化内容探索准备可检查的计算结果。当前重点是历法部分，其他文化内容仍在逐步扩展。

**阶段：早期工具，源码已公开。** [查看仓库](https://github.com/utenkkekou/Metaphysical-data)。用于文化探索，不作为科学预测。
